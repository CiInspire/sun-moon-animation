# ☀️🌙 Orbital UI - Animação Interativa Sol & Lua (Estilo ChatGPT)

## ✨ Recursos

- 🔄 **Morfe Matemático Sol <-> Lua**: Transição contínua com interpolação de cores HSL, raio de plasma e recorte crescente.
- 🧲 **Partículas Magnéticas**: Reatividade ao cursor com força de atração elástica e rotação de feixes.
- 🕹️ **Efeito Parallax 3D Tilt**: Inclinado tridimensional da esfera acompanhando o movimento do mouse.
- 🎨 **Design System Glassmorphism**: Suporte nativo a temas Claro e Escuro com brilhos radiais ambientais.
- 📋 **Exportador de Código**: Snippets em tempo real para HTML, CSS, JS e React (JSX).

## 🚀 Como Executar

Não é necessário instalar nenhuma dependência ou Node.js. Basta clonar o repositório e abrir o `index.html` em qualquer navegador:

```bash
git clone https://github.com/SEU-USUARIO/sun-moon-animation.git
cd sun-moon-animation
# Abra o index.html no seu navegador favorito
```
